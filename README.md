# TRC-20 Token

A secure and lightweight implementation of the TRC-20 token standard for the TRON blockchain.

## Features
- TRC-20 standard compliant
- Compatible with TRON Mainnet
- Works with Web3 wallets including TronLink, TokenPocket, SafePal, and other TRON-compatible wallets
- Standard functions:
  - transfer()
  - approve()
  - allowance()
  - transferFrom()
  - balanceOf()
  - totalSupply()
- Solidity 0.8.x
- Deployable using TronBox or TronIDE
- Clean, well-documented source code
- MIT License

## Use Cases
- Community tokens
- Utility tokens
- Governance tokens
- Learning and development
- Web3 integration
